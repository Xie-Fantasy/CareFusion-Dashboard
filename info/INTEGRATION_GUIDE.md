# YOLOv11-pose与萤石云监控系统集成指南

## 📋 功能概述

本系统成功集成了YOLOv11-pose人体检测后端服务与原有的萤石云监控系统，实现了：

- **双视频源支持**: 在萤石云监控和YOLOv11-pose AI检测之间无缝切换
- **保持云台控制**: 完整保留萤石云摄像头的PTZ（云台）控制功能
- **实时AI检测**: 低延迟的人体检测和标注显示
- **统一界面**: 在同一个监控界面中管理两个视频源

## 🎯 核心特性

### 1. 视频源切换
- **快速切换**: 点击按钮即可在"AI检测"和"萤石云"之间切换
- **状态指示**: 实时显示当前使用的视频源和连接状态
- **智能管理**: 自动管理连接资源，节省带宽

### 2. YOLOv11-pose AI检测功能
- **实时人体检测**: 基于YOLOv11-pose的高精度人体识别
- **检测统计**: 显示检测到的人数、FPS和延迟
- **视觉反馈**: 实时标注检测框和置信度
- **自动重连**: 连接断开时自动重连机制

### 3. 萤石云功能保持
- **云台控制**: 完整的PTZ控制功能（数字键盘控制）
- **视频播放**: 高质量的视频流播放
- **设备管理**: 房间选择和设备状态监控

## 🚀 使用方法

### 启动服务

#### 1. 启动YOLOv11-pose后端服务
```cmd
# 进入yolo-video目录
cd yolo-video

# 激活conda环境
conda activate yolo-detection

# 启动服务
python main.py
```

#### 2. 启动前端界面
```cmd
# 进入info目录
cd info

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

### 操作指南

#### 视频源切换
1. **切换到AI检测模式**:
   - 点击监控画面右上角的"AI检测"按钮
   - 系统会自动连接到YOLOv11-pose服务
   - 状态栏显示连接状态和检测统计

2. **切换到萤石云模式**:
   - 点击监控画面右上角的"萤石云"按钮
   - 自动切换到萤石云视频流
   - 云台控制功能立即可用

#### 云台控制（萤石云模式）
- **上**: 数字键盘8
- **下**: 数字键盘2
- **左**: 数字键盘4
- **右**: 数字键盘6

#### AI检测信息查看
在YOLOv11-pose模式下，视频画面左下角显示：
- **检测人数**: 当前画面中的人数
- **FPS**: 实时处理帧率
- **延迟**: 端到端延迟时间

## ⚙️ 配置说明

### YOLOv11-pose服务配置
编辑 `yolo-video/config.env`:
```env
# RTSP视频流地址
RTSP_URL=rtsp://USER:PASSWORD@CAMERA_HOST:554/STREAM

# 视频处理参数
TARGET_WIDTH=1280
TARGET_HEIGHT=720
TARGET_FPS=25
DETECTION_CONFIDENCE=0.4
```

### 萤石云配置
编辑 `info/ezviz-config.json`:
```json
{
  "ezviz": {
    "accessToken": "your_access_token",
    "deviceSerial": "your_device_serial",
    "cameraNo": 1,
    "accessUrl": "your_access_url",
    "apiUrl": "https://open.ys7.com/api/lapp/v2"
  }
}
```

## 🎨 界面说明

### 视频源指示器
- **绿色徽章**: YOLOv11-pose AI检测模式
- **青色徽章**: 萤石云模式
- **连接状态**: 实时显示连接状态

### 统计信息显示
在AI检测模式下，显示：
- 实时检测人数
- 处理帧率(FPS)

### 控制按钮
- **刷新按钮**: 重新建立连接
- **停止按钮**: 停止视频流（萤石云模式）
- **视频源切换**: 在两个视频源间切换

## 🔧 故障排除

### YOLOv11-pose连接问题
1. **检查服务状态**:
   ```cmd
   curl http://localhost:8000/health
   ```

2. **查看服务日志**:
   - 检查YOLOv11-pose服务的控制台输出
   - 确认RTSP流地址正确

3. **网络检查**:
   - 确保8000端口未被占用
   - 检查防火墙设置

### 萤石云连接问题
1. **Token检查**: 确认accessToken未过期
2. **设备ID**: 验证deviceSerial正确
3. **网络连接**: 检查萤石云服务可达性

### 性能优化
1. **降低延迟**:
   - 减少MAX_QUEUE_SIZE
   - 优化JPEG_QUALITY设置

2. **提高检测精度**:
   - 调整DETECTION_CONFIDENCE
   - 使用更大的YOLO模型
